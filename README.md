# WhatsAuto

A complete SaaS platform for WhatsApp automation. This project aims to streamline communication and automate messages through WhatsApp, providing a user-friendly dashboard and robust API features.

## Features
- **Automated Messaging**: Schedule and automate WhatsApp messages.
- **User Management**: Manage user accounts and permissions.
- **Analytics Dashboard**: View metrics and analytics for message performance.
- **Integration**: Connect with various third-party APIs.

## Getting Started
To get a copy of the project up and running on your local machine for development purposes, follow these instructions:

### Prerequisites
- Node.js
- Docker
- npm/yarn

### Installation
- Clone the repo
- Install dependencies for backend and frontend
- Run the application using Docker
